A chess engine in under 4 KB of Python: negamax alpha-beta search with null-move pruning, principal-variation search, quiescence search, a transposition table and killer moves, on a 0x88 board — built to take on the make.fun house gauntlet.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
